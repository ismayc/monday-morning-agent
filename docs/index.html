An agent that checks the tape.

Everybody knows the Monday morning quarterback, the person who second-guesses every coaching decision after the fact. This one goes back and counts. Every other Monday, live on O'Reilly, an AI agent takes one argument NFL fans cannot stop having and settles it from about a quarter of a million real plays, with every step of its work on screen.

Each episode gets a page here once it is built: how the agent was set up, in plain language, with something you can try yourself.

What ties the eight together

In episode 1 a person reads every filter the agent uses. Each episode after that takes away one piece of that oversight and replaces it with something written down: a definition, a charting rule, a second agent that checks the first, a boundary, a schedule. By the finale the agent does the whole job alone, and the written rules are what make that safe.

The registration page names the eight capabilities in this order, one per episode: transparent queries, shared data definitions as durable memory, consistent visualizations, independent fact-checking, operational boundaries, request triage, self-directed analysis, and scheduled autonomy. Each episode page says which one it is.

Nothing is taken away between episodes. Each one adds a written rule on top of the ones before, so the stack is taller every two weeks.

A written policyA plain-language job description the agent follows. It grows a section at a time across the season.
Small tools that show their workThe agent does not write its own queries. It picks filters for tools that print everything they did.
A short list of what it may runAnything not on the list is refused. In episode 1 the list is one line long.
Public data, cut downPlay-by-play from nflverse, 2021 through this season, with only the columns each question needs.

What this agent does not do

No predictions, no odds, no wagering analysis, and no fantasy advice. That is a design decision, not a disclaimer. The public data carries betting-line columns, and the file the agent can reach does not include them. Deciding what an agent is not allowed to touch is part of building one you can trust.
