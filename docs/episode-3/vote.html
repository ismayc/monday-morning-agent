Which pundit's claim gets audited?

Episode 4 on November 23, 2026 is the pundit audit: a second agent joins as a standing fact-checker, so the agent that does the analysis is never the agent that grades it. The claim it works on is chosen here, by this room, in the poll during episode 3's Q&A. Four claims pundits make every autumn. Pick the one you most want checked.

Which claim should the agent check, with a second agent checking the first?Vote in the poll on your screen. One choice. The result is read aloud before we close.
A

"Icing the kicker works."

Call a timeout just before the kick and the kicker misses more often. The audit would compare kicks that followed a defensive timeout with kicks that did not, at the same distances, and say whether a timeout changes anything.

A pundit's claim since the 1990s, and analytics folk wisdom says the opposite, so one side is wrong.

B

"Home-field advantage is dead."

Crowds do not matter the way they did. The audit would count how often the home team wins and by how much, season by season, and say whether the edge is gone, smaller, or the same.

Said after every upset on the road. The older baseline the claim compares against is before the data this show can see, and the agent would have to say so.

C

"Win the turnover battle, win the game."

The team that gives the ball away less wins. The audit would count it, then ask the harder question: do turnovers cause the win, or does trailing cause the turnovers? The same question episode 1 asked about running the ball.

The claim is in every broadcast. The audit is about what the number can and cannot say.

D

"The new kickoff brought the return back."

The league redesigned the kickoff in 2024 to get returns back into the game. The audit would count returns and touchbacks season by season and say which rule change moved the number, and when.

Two rule changes in two years, so the claim has a date in it, and the chart standard's rule 1 is about to matter.

No numbers on this page, on purpose. The audit's point is that the first agent's number gets checked by a second agent before anyone reads it. Showing the numbers now would decide the vote and spoil the audit. Every one of the four can be settled from the plays on file; what differs is how interesting the honest answer is.
