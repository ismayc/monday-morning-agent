The chart standard, one rule per keypress.

Eight rules for every chart the agent draws, written once in charts/STANDARD.md and enforced by the renderer. Each card is one rule, with the picture it prevents and the picture it makes. The last card is the spec the renderer refused on air. Every number in the pictures is the tool's: the make rate of every field goal, season by season.

1

Every season on file.

A trend runs from 2021, the first season on file, through the current season, with no season skipped and no narrowing to a few weeks. The window is not a choice.

Held by: the renderer checks the command's --seasons must be 2021-2026 this season, and --weeks is refused.

2

Axes start at zero.

A rate axis runs from 0 to 100 percent. A count axis starts at 0. No axis is cut to make a flat line look steep.

Held by: the template the spec has no key for an axis, so there is nothing to cut.

3

The count under every point.

Each rate is drawn with the number of plays behind it, so a rate from 9 kicks does not look like a rate from 900.

Held by: the template every point prints "of N" beneath it, from the tool's row.

4

Two colors, and gray.

The broadcast's two lines: yellow for the thing the claim is about, blue for what it is compared with. Gray marks the current season while it is still being played, labeled with its last week on file. No third series, no third color.

Held by: the template the renderer has three colors and no key to add one.

5

The title is the question.

The chart's title is the question the agent tested, in words a fan would say, ending in a question mark, with no number in it other than a season's year. A title that states the answer is a caption, not a title. The subtitle names the entry, its file and date, and the filters.

Held by: the renderer checks no question mark, or a number that is not a year, and the spec is refused.

6

The source line is the command.

Under the chart, the exact tool command that produced the rows, with the plays and seasons it read, so a reader can rerun it.

Held by: the template the line is printed from the spec's command and the tool's coverage, never typed.

What the bottom of every chart says, with this episode's spec:

Source: node episode-3/query-plays.mjs --trend long-field-goal --seasons 2021-2026  (1,530 games, latest 2026-10-25)
Drawn under charts/STANDARD.md, version 1 (October 26, 2026), from the spec long-field-goal-trend.json, written 2026-11-09.
7

Nothing the tool did not print.

No trend line, no annotation, no second axis, no number typed in by hand. The renderer runs the command and draws what comes back, and that is all it can draw.

Held by: by construction the renderer takes a command, not numbers. The agent cannot hand it a value.

8

The same template every week.

One shape per question. A trend is a line chart of rates by season over a bar chart of attempts per game, laid out the same way every episode, so a reader of episode 5 recognizes episode 3's chart.

Held by: by construction the SVG carries the standard's version, and there is one template to draw with.

✗

The spec the renderer refused on air.

Before the agent runs, a spec that breaks rule 1 is handed to the renderer by hand: the same question, with the trend starting in 2023. It is the chart crime of picking the window, and it is episode-3/bad-chart.json in the repo.

{
  "name": "bad-chart",
  "question": "Are kickers making more of their long field goals than they used to?",
  "tool": "episode-3/query-plays.mjs",
  "command": "--trend field-goal --seasons 2023-2026"
}

What came back, exit code 65, and no file written:

render-chart: REFUSED by rule 1: the command says --seasons 2023-2026; a trend starts at 2021, the first season on file, and ends at 2026, the current one: --seasons 2021-2026. The window is not a choice. Nothing was drawn. The rules are in charts/STANDARD.md, version 1 (October 26, 2026).

The agent gets the same sentence when it breaks a rule, fixes what the sentence names, and runs the renderer again. A refusal is a sentence, not a crash.
