"You have to establish the run." Change one filter and check.

Take every team in every NFL game, work out what share of its plays were runs, and sort the teams into four equal groups. How often did each group win? The answer depends on which plays you count, so every filter is listed with the plays left after it. This is the same output the agent reads.

These filters leave no games to group, so the tool gives no result. That is an answer too: the agent has to say it has nothing, not invent a number.

The bar runs from 0% to 100% of games won, with a line every ten and a heavy line at 50%. The two short grey marks are the middle groups.

    Not in this output: why. A gap is an association between running and winning in the plays kept. It does not say which one causes the other. Teams that are ahead run to use the clock, so winning can cause running.
